Cara Kerja Sistem

CryptoSecure menjamin dua aspek utama keamanan: kerahasiaan dan keutuhan data.

1. Enkripsi - Plaintext menjadi Ciphertext

Pesan yang dimasukkan dienkripsi menggunakan AES-128 CBC menjadi kode acak, kemudian ditandatangani dengan HMAC-SHA256 agar tidak dapat diubah.

2. Dekripsi - Verifikasi sebelum dibuka

Sistem memverifikasi HMAC terlebih dahulu. Jika valid dan kunci sesuai, pesan dikembalikan ke bentuk asli. Jika ada satu karakter yang diubah, sistem akan menolak.

3. Keamanan

AES-128 merupakan standar enkripsi yang digunakan di perbankan. Kunci disimpan aman di Environment Variable server dan tidak tertulis di kode program. Input dibatasi maksimal 500 karakter untuk mencegah penyalahgunaan.

4. Teknologi

Python Flask, Cryptography (Fernet), HTML/CSS (FRONTEND).
