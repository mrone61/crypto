Cara Kerja Sistem

CryptoSecure menjamin dua aspek utama keamanan: kerahasiaan dan keutuhan data.

1. Enkripsi - Plaintext menjadi Ciphertext

Pesan atau file yang dimasukkan dienkripsi menggunakan AES-128 CBC (via Fernet) menjadi kode acak, kemudian ditandatangani dengan HMAC-SHA256 agar tidak dapat diubah.

2. Dekripsi - Verifikasi sebelum dibuka

Sistem memverifikasi HMAC terlebih dahulu. Jika valid dan kunci sesuai, pesan atau file dikembalikan ke bentuk asli. Jika ada satu karakter yang diubah, sistem akan menolak.

3. Enkripsi File - Gambar, Audio & Video

Selain teks, sistem juga bisa mengenkripsi gambar, musik, dan video. File dibaca sebagai bytes, lalu dienkripsi menjadi token teks. Saat didekripsi, file akan kembali utuh dan bisa langsung ditampilkan atau di-download. Maksimal ukuran file 20MB.

4. Keamanan

AES-128 merupakan standar enkripsi yang digunakan di perbankan. Kunci disimpan aman di Environment Variable server dan tidak tertulis di kode program. Input dibatasi untuk mencegah penyalahgunaan.

5. Teknologi

Python Flask, Cryptography (Fernet - AES-128 + HMAC-SHA256), HTML/CSS (FRONTEND).
