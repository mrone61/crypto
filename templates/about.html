ℹ️ About

CryptoSecure adalah sistem sederhana untuk mengamankan pesan menggunakan Python Flask dan kriptografi simetris Fernet. Sistem ini menjamin 2 hal penting dalam Cyber Security: Confidentiality (kerahasiaan) dan Integrity (keutuhan data).

🔒 1. Enkripsi (Plaintext → Ciphertext)

1. User mengetik pesan, contoh: selamat malam
2. Sistem mengambil kunci rahasia FERNET_KEY yang tersimpan aman di server.
3. Pesan dienkripsi dengan AES-128 CBC menjadi kode acak gAAAAAB...
4. Hasilnya ditandatangani digital dengan HMAC-SHA256 agar tidak bisa diubah.

🔓 2. Dekripsi (Ciphertext → Plaintext)

1. User memasukkan Ciphertext.
2. Sistem memverifikasi HMAC terlebih dahulu.
3. Jika HMAC valid & kunci cocok → pesan dikembalikan ke bentuk asli.
4. Jika ada 1 huruf saja yang diubah / kunci salah → sistem menolak dengan pesan "Pesan tidak valid".

🛡️ 3. Kenapa Aman?

• AES-128: Standar enkripsi yang dipakai pemerintah & perbankan.
• HMAC: Mendeteksi jika pesan dimanipulasi di tengah jalan.
• Kunci Paten: Kunci disimpan di Environment Variable Vercel, bukan di kode, jadi tidak berubah-ubah.
• Limit 5000 Karakter: Mencegah serangan DoS / spam.
• Debug Mati di Production: Error server tidak bocor ke hacker.

⚙️ 4. Teknologi Yang Digunakan

• HTML/CSS • Python • Flask • Cryptography (Fernet)
